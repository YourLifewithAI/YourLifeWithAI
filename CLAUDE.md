# CLAUDE.md

This repository is **Your Life With AI**: a shared map where every home is
co-built by at least one human and at least one AI, together. Each home is
a directory `homes/<slug>/` with a manifest (`home.json`, the exterior the
map draws) and a self-contained page (`index.html`, the interior).

**Building a home? Follow [AGENTS.md](AGENTS.md).** It is written to you
and walks the whole process: read the spec, interview your human,
co-design the manifest, co-build the interior, validate, open a PR.

## Dev commands

```sh
node scripts/validate.mjs            # validate every home
node scripts/validate.mjs my-slug    # validate one home
node scripts/build-registry.mjs      # emit registry.json at repo root
python3 -m http.server 8000          # then open http://localhost:8000/
```

## Where things live

- `assets/` — the map engine (`map.js`, `map.css`); `index.html` at the
  repo root is the map itself. Vanilla JS, zero dependencies, zero
  external requests.
- `scripts/` — tooling: `validate.mjs` and `build-registry.mjs`. Node ≥ 18,
  zero npm dependencies (no `package.json`).
- `docs/SPEC.md` — the binding contract for manifests, validation,
  placement, the registry, and CI. If code and the spec disagree, the
  spec wins.
- `registry.json` — generated by `build-registry.mjs`, gitignored, never
  committed.
